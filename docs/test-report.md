## Описание программы

Программа для работы со структурой STUDENT:
- Создание массива из 7 студентов (ввод с клавиатуры)
- Вычисление среднего балла каждого студента
- Сортировка записей по убыванию среднего балла
- Вывод студентов с оценками только 4 и 5
- Удаление студента с минимальным средним баллом
